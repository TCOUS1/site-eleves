# Cours complet Python — SNT seconde

## Contenu

- `cours-python-snt-2de.html` : cours autonome et interactif.
- `progression-python-snt.json` : structure synthétique de la progression.
- `laboratoire-neo/` : mini-environnement du robot virtuel et son JSON maître.

## Utilisation

Ouvrir `cours-python-snt-2de.html` dans un navigateur récent. Le cours fonctionne sans serveur et sans connexion pour toutes les activités internes. Le bouton « Ouvrir le laboratoire Néo » ouvre le simulateur placé dans le sous-dossier associé.

Les réponses, diagnostics et séances cochées sont enregistrés dans le stockage local du navigateur. Le mode enseignant affiche la grille d’évaluation et les repères pédagogiques. L’impression permet de produire une trace papier.

## Droits

Les textes, exercices et illustrations SVG du cours sont originaux. Les références externes sont citées dans la section « Sources, licences et propriété intellectuelle » du fichier HTML.
