# Parcours SNT Python — Néo dans le labyrinthe

Contenu :
- `index.html` : application autonome à ouvrir dans un navigateur moderne ; aucune connexion n'est requise.
- `SNT_ROBOT_MAZE_MASTER.json` : données pédagogiques structurées et réutilisables.

Fonctionnalités :
- labyrinthe vu du dessus ;
- robot orienté et animé ;
- infos-bulles et dialogue court ;
- progression en 9 séances ;
- éditeur avec interpréteur pédagogique d'un sous-ensemble de Python ;
- exécution complète et pas à pas ;
- cours, défis, indices, quiz, correction professeur ;
- sauvegarde locale dans le navigateur ;
- export du travail en JSON.

Important : l'interpréteur est volontairement limité aux structures utilisées dans le parcours. Il ne remplace pas un interpréteur Python complet.
