# Fiche enseignant — Le Web en SNT seconde

## Positionnement

Cette séquence suit la matrice officielle :

1. Observer et décrire ;
2. Acquérir les notions ;
3. Analyser de manière structurée ;
4. Conceptualiser, diagnostiquer et proposer ;
5. S’entraîner et vérifier.

Durée totale indicative : 10 h 30.

## Ce qui est repris du dossier 02-web

Les éléments suivants ont été conservés et développés :

- l’entrée par les usages actuels ;
- la distinction serveur / client ;
- la présentation HTML / CSS / JavaScript ;
- l’affiche A3 réalisée en groupes de trois ;
- la création d’une première page sur un sujet choisi ;
- l’attention portée à l’adaptation aux appareils.

## Ce qui est remplacé

- La vidéo externe n’est plus indispensable.
- Le nombre mondial de sites, difficile à définir et à maintenir à jour,
  n’est plus présenté comme une connaissance centrale.
- Le paquet Scenari et ses nombreuses dépendances sont remplacés par une page
  autonome plus facile à maintenir.
- Le contenu est étendu à toutes les capacités du programme.

## Évaluation possible

### Connaissances
- vocabulaire ;
- décomposition d’URL ;
- rôles de HTML, CSS, HTTP, client et serveur ;
- étapes du moteur de recherche ;
- cookies et licences.

### Capacités
- analyser un document HTML ;
- modifier une page ;
- interpréter une requête et un code d’état ;
- diagnostiquer une URL suspecte ;
- évaluer une source ;
- proposer des réglages de confidentialité ;
- attribuer une ressource.

### Projet
La grille intégrée distingue structure, présentation, analyse technique,
esprit critique, droits et validation.

## Précautions

Les exemples d’URL utilisent principalement le domaine réservé `.example`.
Les simulateurs ne communiquent avec aucun serveur et n’enregistrent pas de
données hors du stockage local du navigateur.
