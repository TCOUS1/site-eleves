1. Titres et paragraphes

Le langage HTML permet de structurer le contenu d'une page web. Il ne sert pas à décorer (c'est le rôle du CSS).

Les titres vont de <h1> à <h6>. Un seul h1 par page en général.

7. Découverte du JavaScript

Le HTML structure la page. Le CSS la décore. Le JavaScript ajoute des interactions.

Exemples de possibilités

  • Changer le thème clair/sombre
  • Modifier la taille du texte
  • Créer des boutons interactifs
  • Sauvegarder des préférences
  • Créer des jeux ou des animations

Ajouter un fichier JavaScript

On place le fichier JavaScript dans un dossier js à la racine du projet. 

projet/
├── index.html
├── style.css
├── img/
│   └── ordinateur.jpg
└── js/
    └── accessibility.js

Puis on relie le fichier JavaScript à la page juste avant la balise </body>. 


<script src="js/accessibility.js"></script>
