# Analyse du cours précédent et choix de reprise

## Qualités repérées

Le dossier `02-web` proposait :

- une entrée simple et motivante ;
- une transcription accessible ;
- une activité orale collective ;
- une première réalisation HTML ;
- un lien vers un cours complémentaire ;
- une interface produite avec Scenari.

## Limites pour devenir la version principale

- la séquence reposait fortement sur une vidéo externe ;
- une estimation du nombre de sites en 2026 n’était pas accompagnée d’une
  source et n’est pas une capacité centrale du programme ;
- la couverture portait surtout sur l’introduction et la création d’une page ;
- URL, HTTP, moteurs de recherche, cookies, confidentialité et droits étaient
  peu ou pas développés ;
- le paquet comprenait de nombreuses dépendances Scenari difficiles à
  maintenir dans la nouvelle matrice.

## Décision

La nouvelle version remplace le cours précédent comme support principal, mais
reprend ses meilleures intentions pédagogiques. L’ancien dossier peut être
conservé comme archive ou comme source d’activité complémentaire.
