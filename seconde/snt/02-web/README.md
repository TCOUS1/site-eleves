# SNT — Le Web

## Ouvrir le cours

Ouvrir `index.html` dans un navigateur récent.

## Fichiers nécessaires

- `style.css`
- `fonts.css`
- `accessibility.js`
- `enseignant.js`
- `matrice-cours.css`
- `matrice-cours.js`
- `web.css`
- `web.js`

Tous sont inclus à la racine du dossier. Les chemins peuvent être modifiés
dans le `<head>` de `index.html`.

## Fonctionnalités

- huit modules ;
- progression enregistrée localement ;
- corrections escamotables ;
- QCM ;
- flashcards ;
- texte à compléter ;
- décomposeur d’URL ;
- éditeur HTML/CSS avec aperçu local ;
- simulateur HTTP ;
- mini moteur de recherche ;
- simulateur de catégories de cookies ;
- activité de diagnostic d’hameçonnage ;
- mode enseignant ;
- impression A4.

## Données et sécurité

Les laboratoires fonctionnent localement. L’iframe d’aperçu utilise l’attribut
`sandbox` et les exemples d’URL utilisent des domaines de documentation.
