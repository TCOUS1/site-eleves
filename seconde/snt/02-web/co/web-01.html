Introduction aux pages Web

Complément : Retranscition actualisée

🌐 1. Le Web aujourd’hui

  • Le Web reste un immense réseau d’ordinateurs connectés.

  • En 2026, on estime qu’il existe environ 1,13 à 1,2 milliard de sites Web (la majorité inactifs, mais existants).

  • Le nombre de sites continue d’augmenter, mais moins vite qu’avant, car beaucoup migrent vers des plateformes (réseaux sociaux, apps…).

🧪 2. À quoi servait le Web au début ?

  • Principalement aux chercheurs pour partager leurs travaux scientifiques.

👥 3. À quoi sert-il aujourd’hui ?

À absolument tout :

  • communiquer (réseaux sociaux)

  • partager des photos/vidéos

  • s’informer

  • acheter, réserver, apprendre

  • travailler en ligne

🖥️ 4. Serveur vs Client

  • Serveur : ordinateur qui héberge un site Web.

  • Client : appareil utilisé pour consulter un site (PC, smartphone, tablette, TV…).

🧱 5. Les trois langages du Web

  • HTML → structure

  • CSS → style

  • JavaScript → interactions

🌍 6. Naviguer sur le Web

  • On utilise un navigateur : Chrome, Firefox, Edge, Safari…

  • Ils cherchent à afficher les sites de la même manière, mais il existe encore des différences d’interprétation.

📱 7. Adapter les sites aux appareils

  • Les appareils clients sont très variés : petits écrans, tactile, haute résolution, mode sombre, etc.

  • Les sites doivent être responsives (s’adapter automatiquement).

🎯 Idée finale

En 2026, créer un site Web reste simple et accessible : HTML + CSS + un peu de JavaScript suffisent pour commencer.

Si tu ne sais pas l’expliquer simplement, c’est que tu ne l’as pas encore bien compris !
