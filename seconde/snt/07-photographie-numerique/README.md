# SNT — La photographie numérique

## Ouvrir le cours

Ouvrir `index.html` dans un navigateur récent.

## Fichiers nécessaires

- `style.css`
- `fonts.css`
- `accessibility.js`
- `enseignant.js`
- `matrice-cours.css`
- `matrice-cours.js`
- `photographie-numerique.css`
- `photographie-numerique.js`

Tous sont inclus. Les chemins peuvent être adaptés dans le `<head>`.

## Contenu

- huit modules ;
- seize corrections ;
- huit QCM ;
- douze flashcards ;
- simulation d’acquisition ;
- microscope de pixels ;
- calculateur de définition ;
- mélange RVB et profondeur ;
- mosaïque de Bayer ;
- lecteur EXIF local ;
- compression JPEG locale ;
- transformations par pixel ;
- histogramme ;
- pipeline photographique ;
- projet final avec export JSON ;
- huit images originales ;
- cinq scripts Python.

## Python

Installer Pillow depuis le dossier `scripts_python` :

```bash
python -m pip install -r requirements.txt
```

## Confidentialité

Le lecteur d’image et les transformations fonctionnent localement. Aucun
fichier choisi par l’utilisateur n’est transmis à un serveur.
