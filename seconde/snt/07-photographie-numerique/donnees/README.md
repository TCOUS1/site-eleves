# Jeux de données et images pédagogiques

Toutes les images sont des créations originales générées pour ce cours.

## Données

- `inventaire_images_demo.csv` : dimensions, format et taille des fichiers ;
- `metadonnees_photo_demo.json` : EXIF et coordonnées fictives ;
- `pixels_16x12_demo.json` : valeurs RVB d’une petite image.

## Images

Le dossier `images` contient une scène originale en PNG et en JPEG à
plusieurs qualités, une mire, une mosaïque de Bayer, un pixel-art et une
photographie JPEG possédant des métadonnées EXIF de démonstration.
