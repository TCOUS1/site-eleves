# Scripts Python — photographie numérique

Installer Pillow si nécessaire :

```bash
python -m pip install -r requirements.txt
```

Exécuter ensuite :

```bash
python analyser_image.py
python transformer_pixels.py
python extraire_contours.py
python comparer_compression.py
python lire_exif.py
```

Les images transformées sont enregistrées dans `resultats_python`.
