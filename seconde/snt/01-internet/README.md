# SNT seconde — Thème Internet

## Contenu

- `index.html` : cours complet selon la matrice officielle ;
- `matrice-cours.css` et `matrice-cours.js` : composants génériques ;
- `internet.css` et `internet.js` : schémas et simulateurs du thème ;
- `style.css`, `fonts.css`, `accessibility.js`, `enseignant.js` : ressources communes ;
- `progression-internet.json` : progression structurée.

## Installation

Copier le dossier sur le site puis adapter dans `index.html` :

- les chemins vers les feuilles CSS et les scripts ;
- le lien vers l’accueil ;
- le lien vers l’espace enseignant.

## Progression

Le parcours comporte sept modules pour une durée indicative de 7 h 35. Il
reprend les capacités du thème « Internet » du programme officiel fourni : IP,
TCP, routage, DNS, pair-à-pair et indépendance par rapport au réseau physique.

## Simulateurs

Les simulateurs DNS, routage et TCP sont entièrement locaux. Ils n’envoient
aucune requête réseau et utilisent des données fictives ou des plages d’adresses
réservées à la documentation.

## Droits

Les schémas et scripts interactifs sont des créations originales. Les normes
techniques sont référencées dans la rubrique Sources du cours.
