# Matériel optionnel et variantes

## Sans matériel

Utiliser les laboratoires HTML et les trois scripts Python exécutables.
Cette modalité couvre toutes les capacités du programme.

## Avec micro:bit

Ressources utiles :
- capteur de température intégré ;
- niveau de luminosité lu par la matrice LED ;
- boutons A et B ;
- affichage 5 × 5 ;
- radio entre cartes ;
- broches pour LED, buzzer ou servomoteur adapté.

Le fichier `microbit_station_salle.py` peut être ouvert dans l’éditeur
Python micro:bit.

## Avec Arduino ou carte équivalente

Adapter :
- l’acquisition à une entrée analogique ou numérique ;
- la commande à une LED ou un relais pédagogique ;
- l’IHM au moniteur série ou à une page locale.

## Précautions

- très basse tension uniquement ;
- résistance avec les LED ;
- alimentation externe et interface adaptée pour les moteurs ;
- aucune connexion directe au secteur ;
- ne pas enregistrer de voix, images ou données personnelles réelles.
