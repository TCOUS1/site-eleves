# SNT — Informatique embarquée et objets connectés

## Ouvrir le cours

Ouvrir `index.html` dans un navigateur récent.

## Fichiers nécessaires

- `style.css`
- `fonts.css`
- `accessibility.js`
- `enseignant.js`
- `matrice-cours.css`
- `matrice-cours.js`
- `objets-connectes.css`
- `objets-connectes.js`

Tous sont inclus. Les chemins peuvent être adaptés dans le `<head>`.

## Contenu

- huit modules ;
- seize corrections escamotables ;
- huit QCM ;
- douze flashcards ;
- salle connectée simulée ;
- automate de porte ;
- générateur MicroPython ;
- IHM interactive ;
- simulateur MQTT ;
- audit de sécurité ;
- export CSV ;
- cinq ressources de données ;
- quatre programmes Python ;
- fiche enseignant, corrigés et guide matériel.

## Données et sécurité

Tous les objets et toutes les mesures sont fictifs. La page ne transmet
aucune donnée vers un serveur et n’exécute pas de code Python arbitraire.
