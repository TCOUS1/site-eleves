# Jeux de données pédagogiques

Tous les objets, mesures, identifiants et scénarios sont fictifs.

## Fichiers

- `inventaire_objets_connectes_demo.csv` : inventaire et caractéristiques ;
- `mesures_salle_connectee_demo.csv` : mesures d’une salle fictive ;
- `messages_mqtt_demo.jsonl` : messages publish/subscribe simulés ;
- `automate_porte_demo.json` : états, événements et transitions ;
- `scenarios_securite_demo.json` : menaces et mesures de protection.

Les CSV sont encodés en UTF-8 et utilisent le point-virgule.
