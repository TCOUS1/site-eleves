# Données pédagogiques
Tous les lieux, itinéraires et coordonnées sont fictifs ou composés pour
l’enseignement. Ils ne doivent pas servir à une navigation réelle.

Fichiers : CSV et GeoJSON de points d’intérêt, trames NMEA, trace GPX,
graphe d’itinéraires et préparation fictive d’une contribution OSM.
