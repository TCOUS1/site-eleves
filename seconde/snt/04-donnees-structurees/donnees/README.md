# Jeux de données pédagogiques
Tous les lieux et nombres sont fictifs. Les CSV utilisent le point-virgule et UTF-8.
- `equipements_publics_demo.csv` : collection principale ;
- `communes_demo.csv` : population et superficie ;
- `frequentation_demo.csv` : fréquentation mensuelle ;
- `donnees_a_nettoyer.csv` : anomalies volontaires ;
- `metadonnees_photo_demo.json` : métadonnées fictives.
