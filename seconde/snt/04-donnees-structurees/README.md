# SNT — Données structurées et leur traitement
Ouvrir `index.html` dans un navigateur récent.

## Inclus
Huit modules, seize corrections, huit QCM, douze flashcards, laboratoire CSV, filtre/tri/calcul, qualité, jointure, données personnelles, anonymisation, open data, métadonnées, cloud, jeux CSV, scripts Python, fiche enseignant et corrigés.

Les chemins CSS/JS peuvent être modifiés dans le `<head>`. Les fichiers fictifs ne décrivent aucune commune réelle. Le sélecteur de fichier travaille localement.
