# Analyse du cours précédent `03-reseaux-sociaux`

## Points forts

Le dossier Scenari proposait une couverture déjà riche :

- définition et histoire ;
- profils et interactions ;
- algorithmes, serveurs et centres de données ;
- graphes et expérience de Milgram ;
- modèle économique ;
- identité numérique ;
- cyberviolence et PHAROS ;
- propagande, désinformation et prévention.

## Éléments réutilisés

La nouvelle version conserve l’organisation thématique et plusieurs situations
de réflexion, notamment :

- comparer les plateformes ;
- comprendre les effets de réseau ;
- étudier les graphes ;
- analyser les revenus publicitaires ;
- protéger l’identité numérique ;
- prévenir et signaler la cyberviolence.

## Éléments remplacés

- Les vidéos devenues indisponibles sont remplacées par des simulations locales.
- Les nombres d’utilisateurs sont datés et associés à un indicateur précis.
- La publicité ciblée est distinguée de la transmission directe de fichiers de
  données aux annonceurs.
- Le cours évite les généralisations médicales ou psychologiques non étayées.
- La distinction entre 3018, urgence, signalement de plateforme et PHAROS est
  précisée.
- Les dépendances Scenari sont remplacées par la matrice HTML officielle.

## Décision

La nouvelle version peut remplacer le dossier précédent comme support
principal. Le dossier Scenari reste utile comme archive de conception.
