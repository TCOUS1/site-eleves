# SNT — Les réseaux sociaux

## Ouvrir le cours

Ouvrir `index.html` dans un navigateur récent.

## Fichiers nécessaires

- `style.css`
- `fonts.css`
- `accessibility.js`
- `enseignant.js`
- `matrice-cours.css`
- `matrice-cours.js`
- `reseaux-sociaux.css`
- `reseaux-sociaux.js`

Les chemins peuvent être modifiés dans le `<head>` de `index.html`.

## Fonctionnalités

- huit modules ;
- progression enregistrée localement ;
- corrections escamotables ;
- huit QCM ;
- douze flashcards ;
- texte à compléter ;
- classement des traces d’identité numérique ;
- simulateur de confidentialité ;
- laboratoire de graphes avec calculs ;
- simulateur de recommandation ;
- modèle économique simplifié ;
- tri de situations de cyberviolence ;
- aide à la décision avant partage ;
- mode enseignant ;
- impression A4.

## Sécurité

Toutes les situations sont fictives et les laboratoires fonctionnent
localement. Aucun témoignage personnel n’est demandé.
