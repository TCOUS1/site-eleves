FICHE 6 - LA COMMUNICATION DANS L’ORGANISATION

Définition : Communication

Communication : processus de transmission et de compréhension de l’information entre acteurs.

Types de communication

Interne / externe

  • Communication interne : communication à l’intérieur de l’organisation, entre ses membres. :

    • Objectifs : informer, coordonner, motiver, créer de la cohésion.

    • Exemples : notes de service, réunions, intranet, mails internes, affichage.

  • Communication externe : communication vers l’extérieur, destinée aux publics externes.

    • Objectifs : promouvoir l’image, informer, vendre, rassurer, attirer.

    • Exemples : publicité, site web, réseaux sociaux, communiqués de presse, relation client.

Formelle / informelle

  • Communication formelle : communication officielle, structurée, prévue par l’organisation :

    • Caractéristiques : écrite ou orale, canaux définis, traçable.

    • Exemples : procédures, rapports, réunions planifiées, organigramme, mails professionnels.

  • Communication informelle : communication spontanée, non officielle, non planifiée.

    • Caractéristiques : rapide, naturelle, souvent relationnelle.

    • Exemples : discussions à la pause, messages instantanés, rumeurs, échanges spontanés.

Ascendante / descendante / horizontale (transversale)

  • Communication descendante : communication qui va du supérieur vers les collaborateurs. :

    • Objectifs : donner des consignes, informer, cadrer.

    • Exemples : directives, objectifs, notes de service.

  • Communication ascendante : communication qui va des collaborateurs vers la hiérarchie :

    • Objectifs : remonter des informations, signaler des problèmes, proposer des idées.

    • Exemples : rapports, enquêtes internes, feedback, demandes.

  • Communication horizontale / transversale : communication entre personnes de même niveau hiérarchique ou sans distinction du niveau hiérarchique :

    • Objectifs : coordonner, collaborer, résoudre des problèmes.

    • Exemples : échanges entre collègues, réunions de projet, coordination inter‑services.

Rôles de la communication

  • coordonner les actions ;

  • transmettre les décisions ;

  • motiver et intégrer les acteurs.

Attention : Des dysfonctionnements sont possibles

Type de dysfonctionnement

Explication

Exemples

BRUIT

Tout élément qui perturbe ou altère le message entre l’émetteur et le récepteur. Ce n’est pas forcément un bruit physique.

  • surcharge d’informations

  • message mal formulé

  • interface numérique qui bug

  • différence de vocabulaire ou de culture

  • distraction, fatigue, stress

  • préjugés qui déforment la réception

Effet : le message arrive déformé, incomplet ou mal compris.

FILTRAGE

modification volontaire ou involontaire du message avant qu’il n’arrive au destinataire.

  • un intermédiaire qui “adoucit” ou “durcit” une information

  • un collaborateur qui ne transmet qu’une partie du message

  • hiérarchie qui sélectionne ce qu’elle remonte ou redescend

  • algorithmes / outils qui trient les informations

Effet : le message est sélectif, parfois biaisé.

MAUVAISE INTERPRÉTATION

Le récepteur comprend autre chose que ce que l’émetteur voulait dire.

  • ambiguïté dans les mots utilisés

  • ironie mal perçue

  • différences culturelles ou professionnelles

  • interprétation influencée par l’humeur ou les attentes

  • message trop vague ou trop technique

Effet : le sens est décalé, ce qui peut créer erreurs, tensions ou conflits.

Pour aller plus loin - École des relations humaines (Mayo)

Idée centrale

La motivation et la performance dépendent surtout des relations humaines, pas seulement des conditions matérielles ou de l’organisation du travail.

Complément : Constat clé : les expériences de Hawthorne

Mayo observe que :

  • ce ne sont pas les changements techniques (lumière, pauses…) qui expliquent la productivité,

  • mais le sentiment d’attention, la reconnaissance, la cohésion du groupe.

Le simple fait d’être considéré augmente la motivation (effet Hawthorne).

Complément : Principes essentiels

  • Le travail est social avant d’être technique.

  • Les salariés ont besoin de reconnaissance, écoute, participation.

  • Les relations de groupe influencent fortement le comportement.

  • Le manager doit favoriser la communication, la coopération, le climat humain.

Fondamental :

La performance dépend de la qualité des relations humaines : la motivation a tendance à augmenter quand on se sent valorisé, intégré, soutenu.
