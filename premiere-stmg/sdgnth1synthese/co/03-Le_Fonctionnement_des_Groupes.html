FICHE 3 - LE FONCTIONNEMENT DES GROUPES

Définition : Groupe / action collective

  • Groupe : ensemble d’individus en interaction partageant un objectif commun.

  • Action collective : coordination volontaire des actions individuelles.

Types de groupes

  • Groupes formels : créés par l’organisation (services, équipes).

  • Groupes informels : issus des relations sociales.

Structure du groupe

Un groupe repose sur :

  • des rôles (fonctions attendues),

  • des statuts (position hiérarchique ou symbolique),

  • des normes (règles implicites ou explicites).

    • Règles explicites : règles formalisées, annoncées clairement, connues de tous. Elles sont écrites ou verbalisées.

    • Règles implicites : règles non écrites, non dites, mais partagées tacitement par les membres du groupe. Elles émergent naturellement avec le temps.

Pour aller plus loin - Kurt Lewin : dynamique de groupe

Idée centrale

Le comportement d’un individu dépend du groupe dans lequel il évolue. Le groupe est un système en interaction, qui influence les attitudes, les décisions et la motivation.

Le groupe comme “champ de forces”

Lewin décrit le groupe comme un ensemble de forces qui s’opposent ou se complètent :

  • Forces favorables → facilitent l’action, le changement.

  • Forces résistantes → freinent l’action, créent l’inertie.

Fondamental :

Le rôle du leader / enseignant / manager : réduire les forces de résistance plutôt que d’augmenter la pression.

Interdépendance des membres

Les individus sont interconnectés :

  • ce que fait l’un influence les autres,

  • les comportements se régulent mutuellement,

  • la cohésion ou les tensions se propagent.

Fondamental :

Le groupe fonctionne comme un tout, pas comme une somme d’individus.

Rôles, normes et structure

Lewin montre que tout groupe développe :

  • des rôles (leader, médiateur, expert, suiveur…),

  • des normes (règles implicites),

  • une structure (relations, statuts, sous‑groupes).

Fondamental :

Ces éléments déterminent la cohésion et l’efficacité collective.

Le processus de changement (modèle en 3 étapes)

  1. Dégel : remettre en question les habitudes, créer une prise de conscience.

  2. Changement : expérimenter de nouveaux comportements.

  3. Regel : stabiliser les nouvelles pratiques.

Fondamental :

Modèle clé pour comprendre la conduite du changement dans les organisations.

Conclusion

Lewin est le père de la dynamique de groupe :

  • il montre que le groupe influence fortement l’individu,

  • que les comportements dépendent du contexte social,

  • et que le changement nécessite une transformation du système, pas seulement des individus.

Influence du groupe

Le groupe influence les comportements :

  • conformité aux normes ;

  • recherche de reconnaissance ;

  • pression du collectif.

Conclusion

Fondamental :

Le groupe structure les comportements individuels et facilite l’action collective.
