# BTS GPME — v3.0.2

## Intégration PGI / Odoo

Cette version ajoute une couche instrumentale dédiée au PGI utilisé dans la formation : Odoo.

- parcours élève `entrainement/odoo.html` ;
- prolongements Odoo dans M01, M02, M03, M05, M06 et M07 ;
- ressource transversale PGI enrichie avec une mise en pratique Odoo ;
- recherche locale : `odoo`, `crm odoo`, `stock odoo`, `facture odoo`, etc. orientent vers la ressource PGI ;
- page enseignant de mise en œuvre lorsque l'espace enseignant est présent.

Les consignes restent fonctionnelles et ne dépendent pas d'une version précise d'Odoo : les menus peuvent varier selon la version, les modules installés, les droits et le paramétrage.
