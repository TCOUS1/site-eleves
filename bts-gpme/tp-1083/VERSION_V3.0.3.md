# Version 3.0.3 — Impression / PDF et Mode d’emploi

Cette version ajoute deux fonctions volontaires de consultation, sans modifier les méthodes métier ni le moteur de recherche.

## Imprimer / enregistrer en PDF

- 145 fiches ressources : impression dédiée.
- 3 méthodes transversales de démarrage : impression dédiée.
- Fiche pratique Odoo : impression dédiée.
- 343 cartes **Connaissances BTS GPME** : impression d’une connaissance à la fois.
- Mise en page A4 : navigation, boutons et contrôles interactifs retirés du document imprimé.
- Pour une ressource, la vue **Essentiel / Complet** et les blocs actuellement ouverts sont respectés.
- Aucun PDF n’est pré-généré : le navigateur ouvre sa boîte de dialogue d’impression et peut proposer **Enregistrer au format PDF**.

## Mode d’emploi à la demande

Un bouton **Mode d’emploi** est ajouté aux principaux espaces élèves. Il ouvre une aide contextuelle refermable :

- centre de ressources ;
- missions et index des missions ;
- fiches ressources ;
- Connaissances ;
- méthodes transversales ;
- Odoo / entraînements ;
- référentiel intégré.

L’aide reste fermée par défaut, ne donne pas la réponse métier et peut être fermée par le bouton **Fermer**, la croix ou la touche **Échap** lorsque le navigateur prend en charge la boîte de dialogue native.

La v3.0.3 conserve les correctifs v3.0.1 et l’intégration PGI / Odoo v3.0.2.
