# v4.1 — application unifiée

Principes :
- une seule application, pas de distribution élève/enseignant séparée ;
- navigation à gauche, lecture à droite ;
- accueil sans résultats avant requête ;
- progression d’accueil : Comprendre une notion → Savoir comment faire → M’entraîner ;
- notions consultables comme objets précis, avec exploration A–Z par survol/clic ;
- situations PGI présentées par besoin professionnel, Odoo étant l’outil de mise en pratique ;
- référentiel conservant son articulation propre sous la même charte graphique ;
- retours élèves centralisés via PHP + SQLite ;
- badge Maintenance = nombre exact de demandes non traitées ;
- traitement, suppression et export CSV dans Maintenance.
