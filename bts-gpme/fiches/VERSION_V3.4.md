# Version 3.4 — retour d’usage en classe

## Objectif

Cette version part d’un constat d’usage : lors d’un TP de gestion des risques, les étudiants ont d’abord eu besoin de comprendre **où se situent les activités de l’entreprise** avant de pouvoir rechercher les risques.

## Ajouts

1. **R-TR-015 — Chaîne de valeur de Porter avant l’identification des risques**
   - activités principales / activités de soutien ;
   - adaptation au fonctionnement réel d’une PME ;
   - dépendances et vulnérabilités ;
   - passage activité → risque potentiel → preuve → formulation du risque.

2. **R-TR-016 — Présenter et caractériser une PME**
   - identité, métier, taille si connue, marché, organisation, partenaires, ressources et contexte ;
   - sélection des informations utiles à la mission ;
   - distinction entre fait, interprétation et information manquante.

## Intégration pédagogique

Le parcours guidé de M10 comporte désormais deux préparations en amont :

> comprendre la PME → cartographier ses activités → identifier/formuler les risques → évaluer/hiérarchiser → représenter la criticité → préparer le traitement.

R-B2-011 renvoie également vers ces deux méthodes lorsqu’un étudiant ne sait pas encore où chercher les risques.

## Recherche

Les requêtes suivantes sont explicitement rapprochées des nouvelles fiches :
- chaîne de valeur / Porter ;
- activités cœur de métier ;
- fonctions support ;
- où chercher les risques ;
- présenter / caractériser une entreprise ou une PME ;
- fiche d’identité entreprise.
