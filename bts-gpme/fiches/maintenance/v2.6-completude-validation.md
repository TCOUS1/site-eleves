# Validation v2.6 — complétude des notions et navigation sémantique

## Objet
Cette itération prolonge la v2.5 sans reconstruire les 145 ressources. Elle traite les manques systématiques révélés après les stress-tests ECOTERMIC et MONT.AMB : vocabulaire débutant incomplet, glossaire partiel, index de recherche trop bruité et ressources liées parfois trop mécaniques.

## Résultats principaux
- 145 ressources conservées ;
- 30 missions strictement inchangées par rapport à la v2.5 ;
- au moins 3 notions définies dans chacune des 145 ressources ;
- 332 entrées de glossaire, toutes reliées directement à au moins une ressource ;
- 501 entrées dans l'exploration alphabétique ;
- 0 code `#` affiché dans les termes alphabétiques ;
- 0 entrée structurée (notion ou référentiel) sans ressource associée ;
- index de recherche reconstruit à partir du contenu utile des fiches et non plus de la page entière ;
- titres, besoins d'usage et résultats attendus : 145/145 retrouvent leur propre ressource en première position lors du test automatique ;
- 21 requêtes de stress-test spécialisées : ressource attendue en première position ;
- 0 lien relatif cassé sur les pages de la bibliothèque ;
- 0 ancre cassée sur les pages élève ;
- 0 identifiant HTML dupliqué ;
- 0 hashtag visible non officiel sur les ressources, missions et référentiel ;
- syntaxe JavaScript validée par `node --check`.

## Non-régression
En retirant les zones volontairement modifiées (`Notions indispensables`, `Ressources liées`, `Sources`), le texte des 145 ressources est identique à la v2.5. Les 30 fichiers de missions sont identiques octet par octet à la v2.5.

## Limite technique connue
Les anciennes pages d'audit de la base v1.9 contiennent des ancres vers `referentiel/savoirs.html` qui n'existent pas dans ce fichier historique. Ces liens préexistaient à la v2.6 et ne concernent pas le parcours élève actuel, qui utilise `referentiel/index.html`.
