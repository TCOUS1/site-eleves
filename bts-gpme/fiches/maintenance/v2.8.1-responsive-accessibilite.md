# Validation responsive et accessibilité v2.8.1

## Contrôles réussis
- `meta viewport` présent sur toutes les pages élève contrôlées ;
- règles CSS responsive `@media` présentes ;
- index Missions contenu dans la largeur maximale commune et non étiré sur tout l’écran ;
- pictogrammes SVG embarqués dans le CSS, sans chargement SVG externe fragile ;
- mode clair/foncé, taille 80–160 % et mode DYS persistants ;
- détection explicite de la disponibilité d’OpenDyslexic ;
- aucune police binaire redistribuée dans l’archive ;
- barre DYS présente sur les 184 pages cœur contrôlées.

## Limite de l’environnement
Un test de rendu réel a été tenté avec Chromium/Playwright via serveur HTTP local. L’environnement d’exécution bloque administrativement la navigation locale avec `ERR_BLOCKED_BY_ADMINISTRATOR`. La v2.8.1 ne revendique donc pas une certification visuelle multi-navigateurs automatisée.

Les contrôles structurels et CSS sont passés, mais un dernier test sur Chrome/Edge/Firefox et smartphone/tablette réels reste utile avant diffusion institutionnelle.


> v2.8.1 ne modifie pas le fond concerné par cet audit ; les conclusions restent inchangées.
