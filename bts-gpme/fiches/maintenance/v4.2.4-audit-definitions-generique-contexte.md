# V4.2.4 — Audit des définitions : objet générique et contexte d’application

Date : 24/09/2026

## Principe retenu
Une définition ne doit pas présenter comme universelle une acception valable seulement dans un champ disciplinaire ou professionnel.

Ordre attendu : **objet → définition générique/invariante → application au domaine → définition spécialisée si nécessaire**.

Trois cas sont distingués :
1. notion générique : définition générale puis précision « Dans le cadre de… » ;
2. terme polysémique sans noyau commun pédagogiquement utile : domaine rendu visible dans le titre ;
3. objet intrinsèquement spécialisé : définition directe, sans généralisation artificielle.
