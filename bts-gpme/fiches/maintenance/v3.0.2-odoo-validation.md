# Validation v3.0.2 — intégration PGI / Odoo

## Périmètre

La v3.0.2 ajoute une couche instrumentale Odoo sans créer de nouvelle méthode métier.

- Page élève : `entrainement/odoo.html`
- Page enseignant : `enseignant/odoo.html`
- Missions reliées : M01, M02, M03, M05, M06, M07
- Ressource transversale enrichie : R-TR-012 — extraction/contrôle de données du PGI
- Notion PGI : Odoo ajouté comme exemple utilisé dans la formation
- Recherche : `Odoo`, `ERP`, `CRM Odoo`, `stock Odoo`, `facture Odoo`, etc. orientent vers R-TR-012

## Principes pédagogiques

1. La mission professionnelle reste première ; Odoo est un environnement d'exécution et de preuve.
2. Les consignes décrivent des fonctions métier, pas des coordonnées d'écran.
3. Les menus peuvent varier selon la version, les modules, les droits et le paramétrage.
4. Toute action engageante (confirmation de commande, comptabilisation, rapprochement, modification d'une règle de stock) reste soumise à la consigne et aux droits.
5. Les exports/imports doivent conserver la traçabilité ; un import n'est réalisé que sur une base ou des données autorisées.

## Limite volontaire

Cette version ne simule pas Odoo et ne dépend pas d'un jeu de données particulier. Les exercices deviennent réellement exécutables dans l'instance de l'établissement lorsque l'enseignant fournit la base, les droits et les données de formation.
