### Correction v3.3

La feuille d’impression ne force plus l’ouverture de tous les éléments `<details>`. Un bloc fermé reste fermé à l’impression ; un bloc ouvert reste imprimable. Le comportement spécifique d’impression d’une connaissance isolée reste géré par son mécanisme dédié.

## Contrôles techniques

- aucun lien local cassé dans la distribution élève ;
- aucun lien local cassé dans la distribution enseignant ;
- syntaxe de tous les fichiers JavaScript vérifiée avec `node --check` ;
- les écarts de contenu entre distributions élève et enseignant n’augmentent pas : 36 écarts dans la base v3.2, 35 dans la v3.3 (le classeur M03 est désormais harmonisé sur la version améliorée).

## Limite du contrôle automatisé dans cet environnement

Une tentative de test end-to-end dans Chromium a été effectuée, mais les navigations `http://127.0.0.1/...` et `file://...` sont bloquées par la politique d’administration de l’environnement d’exécution. Aucun résultat de rendu navigateur n’est donc revendiqué ici. Une vérification manuelle dans un navigateur reste recommandée avant diffusion définitive aux étudiants, notamment pour l’impression PDF.

## Verdict

**v3.3 fusionnée validée sur la structure, les contenus, les liens, les attributs fonctionnels et la syntaxe JavaScript.**
