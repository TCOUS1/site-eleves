# Validation v3.0.3 — Impression / PDF et Mode d’emploi

- Fiches ressources : **145/145** avec Mode d’emploi et impression/PDF.
- Missions : **30/30** avec Mode d’emploi contextuel.
- Connaissances : **343/343** cartes imprimables individuellement.
- Méthodes transversales de démarrage : **3/3** imprimables et avec Mode d’emploi.
- Odoo : **Mode d’emploi + impression/PDF**.
- Centre de ressources, index Missions, Référentiel et Entraînements : Mode d’emploi contextuel.
- JavaScript : syntaxe contrôlée par Node.
- Liens/ancres locaux ou problèmes structurels détectés : **0**.

Le validateur traite séparément le chemin, les paramètres de requête (`?q=`, `?from=`) et les ancres afin de ne pas produire de faux liens cassés.

Limite : l’impression utilise la boîte de dialogue native du navigateur ; le rendu exact et l’intitulé « Enregistrer au format PDF » dépendent du navigateur et du système.

## Test navigateur dans cet environnement

Une tentative de chargement Chromium headless sur une fiche locale n’a pas abouti proprement dans le délai disponible (erreurs d’environnement/DBus et absence de DOM final exploitable). La version ne doit donc pas être présentée comme certifiée visuellement multi-navigateurs. Les contrôles livrés sont structurels et syntaxiques ; un test réel sur les postes et navigateurs de l’établissement reste recommandé.
