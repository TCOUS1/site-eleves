## Utiliser la bibliothèque
- **Recherche** : partir d'une situation ou d'un besoin professionnel, avec ses propres mots.
- **Alphabet** : retrouver un terme que l'on reconnaîtra en le voyant.
- **Connaissances BTS GPME** : comprendre ou réviser une notion.
- **Missions** : s'entraîner dans des situations professionnelles.
- **Référentiel** : relier le travail aux attendus officiels reproduits dans la bibliothèque.

## Accessibilité
Le mode DYS, la taille de texte et le fond clair/foncé restent disponibles. Les fichiers OpenDyslexic ne sont pas redistribués ; les installateurs peuvent les extraire depuis la matrice locale fournie par l'utilisateur.
