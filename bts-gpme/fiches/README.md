# Prototype BTS GPME — fournisseur accessible V0.4

## Ouvrir

Ouvrir `index.html` dans un navigateur récent.

## Fonctions ajoutées

- lien d’évitement vers le contenu principal ;
- menu d’accessibilité utilisable au clavier ;
- mode sombre par défaut et mode clair ;
- mode dyslexie avec police de repli ;
- augmentation et réduction de la taille du texte ;
- mémorisation locale des réglages ;
- réinitialisation ;
- impression ;
- navigation active annoncée avec `aria-current` ;
- tableaux défilables sur smartphone ;
- styles pour la réduction des animations ;
- pied de page demandé.

## Police OpenDyslexic

Le fichier `fonts.css` fourni est inclus. Les fichiers de police ne sont pas distribués dans ce
paquet. Lorsque ces fichiers ne sont pas présents dans le dossier `fonts`, le navigateur utilise
automatiquement Arial ou Verdana comme solution de repli.
