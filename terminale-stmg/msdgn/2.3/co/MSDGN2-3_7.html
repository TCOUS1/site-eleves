Synthèse communication interne

[1]

Retrouvez les mots manquants.

La communication interne s’adresse à toutes les parties prenantes internes de l’organisation. On aura recours à une communication :

  • descendante, c’est-à-dire de la hiérarchie vers les salariés, pour informer, expliquer et faire adhérer ;

  • ascendante, des salariés vers la hiérarchie, pour identifier les dysfonctionnements, pour faire remonter les besoins ;

  • transversale / horizontale entre tous les acteurs internes sans distinction de niveau hiérarchique pour échanger sur un objet, pour se coordonner.
