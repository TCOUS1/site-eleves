Les 3 formes (sens) de communication interne

Fondamental : Descendante - Ascendante - Transversale / Horizontale

La communication interne peut prendre trois formes selon le sens de circulation de l'information :

⬇ DESCENDANTE

⬆ ASCENDANTE

↔ TRANSVERSALE

De la hiérarchie vers les salariés.

But : diffuser les informations clés, les objectifs, le règlement intérieur et résoudre les conflits internes.

Outils : réunion d'info, journal, intranet, newsletter, affichage, livret d'accueil

Des salariés vers la hiérarchie.

But : faire remonter les réclamations, les besoins, les suggestions, identifier les dysfonctionnements.

Outils : boîte à idées, sondage interne

Entre tous les acteurs sans distinction hiérarchique.

But : améliorer le management, libérer la parole, faciliter les échanges.

Outils : réunion de travail, e-mail, séminaire, RSE, messagerie instantanée
