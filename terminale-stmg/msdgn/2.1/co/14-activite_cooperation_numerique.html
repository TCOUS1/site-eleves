Exercice : Créer un espace de coopération RGPD-friendly

Objectifs pédagogiques

Les élèves doivent :

  • découvrir les outils collaboratifs proposés par « La Digitale »

  • comprendre l’importance du RGPD

  • mobiliser le vocabulaire de la coopération

  • expérimenter le travail coopératif réel

Organisation

Des groupes de 3 à 4 élèves sont tirés au choix aléatoirement .

Votre situation : vous êtes une équipe projet en entreprise.

Consigne : Vous devez organiser le lancement d’un nouveau produit en utilisant les outils de La Digitale.

RÈGLE IMPORTANTE (coopération et évaluation)

Chaque élève doit indiquer précisément ce qu’il a réalisé dans le travail (dans le document ou à l’oral).

Objectifs :

  • vérifier que tout le monde participe

  • éviter le travail “inégal”

  • valoriser l’implication individuelle

Évaluation :

  • la production est notée collectivement

  • MAIS la note peut être modulée individuellement selon l’implication de chacun

Exemple :

Élève A : brainstorming

Élève B : organisation du projet

Élève C : analyse RGPD

Question

Découverte des outils (10-15 min) - En classe

Tester :

  • Digipad

  • Digidoc

  • Digiconf

Question

Travail coopératif (30-40 min) - Hors classe

Créer un espace collaboratif avec :

  • 3 idées (brainstorming)

  • organisation des tâches

  • planning

Utiliser :

  • un outil collaboratif

  • un mode synchrone ou asynchrone

Question

Intégrer le RGPD (15-20 min) - Hors classe

Répondre :

  • pourquoi ces outils respectent mieux les données ?

  • quels risques avec d’autres outils ?

  • pourquoi protéger les données ?

Question

Restitution orale (10-15 min) - En classe

Présenter :

  • outils utilisés

  • organisation

  • répartition du travail (obligatoire)

  • intérêt du RGPD

Indice

Notions à utiliser

  • coopération

  • groupe de projet

  • outil collaboratif

  • synchrone / asynchrone

  • RGPD

  • données personnelles

  • intranet

Solution

Le travail coopératif nécessite une implication de tous les membres du groupe ; les outils collaboratifs facilitent cette organisation tout en permettant, avec des solutions comme celles de La Digitale, de respecter les règles du RGPD et de protéger les données personnelles.
