Le rôle du système d’information

Définition : Système d’information

Le système d'information (SI) est l'ensemble des ressources humaines, matérielles, logicielles et organisationnelles permettant de collecter, stocker, traiter et diffuser l'information au sein d'une organisation.

Le SI constitue la colonne vertébrale numérique de l'organisation.

Sans lui, les différents services travailleraient de manière isolée.

Fondamental : Pourquoi le système d'information est-il indispensable ?

Lorsqu'un client interagit avec une organisation, il laisse de nombreuses informations :

  • demande de renseignement ;

  • devis ;

  • commande ;

  • paiement ;

  • livraison ;

  • réclamation ;

  • avis client.

Toutes ces informations doivent être conservées, mises à jour et partagées entre les différents services.

Le système d'information permet justement de centraliser ces informations afin qu'elles soient accessibles aux personnes qui en ont besoin.

Exemple : Exemple : l'achat d'un ordinateur portable

Imaginons qu'un client commande un ordinateur sur un site marchand.

Service commercial

Service logistique

Service comptabilité

Service après-vente

Le vendeur enregistre :

  • l'identité du client ;

  • le produit commandé ;

  • les coordonnées de livraison.

Ces informations sont intégrées dans le SI.

Grâce au SI, le service logistique sait :

  • quel produit préparer ;

  • où l'expédier ;

  • à quelle date.

Il n'a pas besoin de redemander les informations.

Le paiement est automatiquement enregistré.

La facture peut être générée.

Quelques semaines plus tard, le client contacte le SAV.

Le conseiller retrouve immédiatement :

  • la date d'achat ;

  • le produit concerné ;

  • la garantie ;

  • les précédents échanges.

Le client n'a pas besoin de tout réexpliquer.

Complément : Le SI favorise une vision globale du client

Chaque service enrichit progressivement la connaissance du client.

Le système d'information centralise notamment :

Les commandes

  • produits achetés ;

  • quantités ;

  • dates ;

  • fréquence d'achat.

Ces informations permettent d'analyser les habitudes de consommation.

Les paiements

  • montant des achats ;

  • mode de paiement ;

  • historique financier.

L'entreprise peut suivre la valeur du client.

Les interactions

  • appels téléphoniques ;

  • courriels ;

  • conversations sur les réseaux sociaux ;

  • échanges avec un chatbot.

L'organisation conserve une mémoire de la relation.

Le SAV

  • réclamations ;

  • retours produits ;

  • incidents rencontrés ;

  • niveau de satisfaction.

Ces informations permettent d'améliorer les produits et les services.

Le SI améliore la relation client grâce au partage de l'information :

L'organisation gagne en efficacité

Le client n'a pas à répéter plusieurs fois les mêmes informations.

La communication devient plus cohérente

Tous les services disposent des mêmes données.

Les décisions sont plus pertinentes

L'entreprise connaît mieux ses clients et peut adapter son offre.

La satisfaction augmente

Les réponses sont plus rapides et plus personnalisées.

Fondamental : Intérêt du système d’information

Le système d'information permet de centraliser et partager les informations relatives aux clients afin d'améliorer la coordination entre les services, la qualité de la relation client et la prise de décision.
