Outils numériques et RGPD

Les outils numériques

Définition : Outils numériques

Les outils numériques sont des outils informatiques utilisés dans l’entreprise.

Complément :

À quoi servent-ils ?

Exemples d’outils

  • communiquer

  • travailler ensemble

  • gérer les informations

  • Mail → communiquer

  • Teams / outils collaboratifs → travailler en équipe

  • CRM → gérer les clients

  • PGI (ERP) → gérer toute l’entreprise

  • Cloud → stocker des données en ligne

Les avantages du numérique

Les outils numériques permettent :

  • travailler plus vite

  • partager l’information

  • mieux communiquer

  • améliorer le travail en équipe (outils collaboratifs)

Les risques du numérique

Les outils numériques peuvent poser des problèmes :

  • piratage (hack)

  • vol de données

  • fuite d’informations

  • dépendance (si panne)

Les données personnelles

Définition : Données à caractère personnel

Données permettant d’identifier directement ou indirectement un individu.

Exemple : Exemples

  • nom

  • adresse

  • mail

  • numéro de téléphone

Le RGPD

Définition : Le RGPD

Le RGPD est une règlement européen qui vise à protéger les personnes et leurs données.

Un règlement lorsqu’il est voté doit s’appliquer directement par tout les pays membres.

Fondamental : Droit des individus et obligations des sociétés nées du RGPD

Droits des individus

Obligations des entreprises

Être informé de l’utilisation des données

Informer clairement les personnes

Donner ou refuser son consentement

Demander l’accord avant de collecter

Accéder à ses données

Permettre l’accès aux données

Modifier ses données (rectification)

Corriger les données si besoin

Supprimer ses données (droit à l’oubli)

Supprimer les données si demandé

S’opposer à l’utilisation des données

Respecter le refus d’utilisation

Protéger ses données personnelles

Sécuriser les données (éviter piratage)

Attention : Pourquoi c’est important pour l’entreprise

Respecter le RGPD permet :

  • éviter des sanctions

  • garder la confiance des clients

  • protéger les données
