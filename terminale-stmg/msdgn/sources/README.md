# MSDGN — Enseignement commun — Cours OAC V0.2

Ce paquet constitue la première didactisation des douze problématiques de l’enseignement
commun de terminale STMG.

## Contenu

- 5 cours pour le thème 1
- 3 cours pour le thème 2
- 4 cours pour le thème 3
- un guide pédagogique
- un fichier de progression
- un corrigé enseignant
- le corpus de connaissances V0.2

## Utilisation

Les dossiers sont volontairement fictifs afin d’éviter les problèmes de droit et les données
rapidement obsolètes. Ils serviront de base avant le remplacement ou l’enrichissement par :

- des sujets de baccalauréat
- des annexes réelles autorisées
- des ressources libres de droits
- des documents produits par l’enseignant

Cette version n’est pas encore la version HTML.

## Accroches

La version V0.2 ajoute un cadre de sélection des accroches et une exploitation complète de la
publicité De Lijn dans le cours 2.1. La vidéo reste hébergée sur sa plateforme d’origine.
