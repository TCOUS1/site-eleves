# MSDGN — Enseignement commun — Version HTML

## Démarrage

Ouvrir `index.html` dans un navigateur récent.

## Architecture

- `index.html` : portail des douze cours
- `methodes.html` : méthodes et verbes d’action
- `cours/` : douze cours autonomes
- `enseignant/` : repères enseignant
- `assets/` : CSS et JavaScript partagés
- `sources/` : corpus et cours Markdown ayant servi à la génération
- `manifest.json` : inventaire du paquet

## Adaptation à la terminale STMG

Chaque cours comprend :

- une problématique directrice
- une mise en tension
- une accroche lorsqu’elle est disponible
- un dossier d’organisation avec annexes
- les phases Observer, Analyser et Conceptualiser
- des consignes formulées par des verbes d’action
- une aide méthodologique propre à chaque verbe
- des espaces de réponse enregistrés localement
- une réponse de référence à la problématique
- un entraînement de type baccalauréat
- des repères de correction en mode enseignant

## Données

Les réponses et la progression restent dans le stockage local du navigateur. Aucune donnée
n’est transmise à un serveur par les fichiers du paquet.

## Vidéo

La publicité De Lijn du cours 2.1 est intégrée depuis YouTube en mode de confidentialité
renforcée. Le fichier vidéo n’est pas copié dans le paquet.
